## 3. Sprint 1 must-haves by next stand-up

1. **Repo live** — shared GitHub/GitLab, README, folder structure; every member has committed something (repo evidence = 20% of this sprint).
2. **Stakeholder analysis** — Producers (varying tech skill), Customers (3 segments), Network Admin, plus external orgs (payment sandbox, organic-certification verification, delivery/collection).
3. **Strategic-level BPMN** — one high-level model: major processes, org functions/responsibilities, key actors, external orgs, interactions. **High abstraction only — no lane-level detail.** (50% item.)
4. **Major process list** — e.g. product listing/inventory, order+checkout+payment, traceability/incident, payouts/commission, notifications.
5. **Two candidate functionalities** scoped + agreed with the module team.
6. **Initial product backlog** — user stories with acceptance criteria, MoSCoW, traceable to stakeholders.
7. **Sprint plan** — tasks split and delegated to all 5 on a board (GitHub Projects / Jira / Trello).
8. **Start the i\*** — optional this sprint.

Note: the strategic BPMN is the only *diagram* requirement now. Do not use AI to generate i*/BPMN diagrams — it is an assessment offence.
